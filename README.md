# Borneo Spring API

This repository is a production-grade Spring Boot backend built entirely from scratch, featuring custom authentication, MariaDB integration, and Docker orchestration.

The project uses Java and its 25th version (LTS), as well as Spring Boot 4 for the web framework and JDBC for database connectivity.

## 🛠️ Stack Overview
- **Language(s):** Java 25
- **Technologies:** Spring Boot 4, Spring Security, MariaDB
- **Containerization:** Docker & Docker Compose
- **Build Tool:** Gradle
- **IDE:** IntelliJ IDEA

## 📂 Folder Structure
- **'src/main/java/borneo/'** contains the main application, controllers, and security configuration
- **'src/main/resources/'** contains application properties and static resources
- **'compose.yaml'** contains the Docker Compose configuration for the MariaDB database
- **'build.gradle'** contains the dependencies and build configuration
